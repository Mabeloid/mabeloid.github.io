the tunic archipelago tracker is a discord bot that logs into a slot and sends a discord message that pings you whenever you get a (non-filler) item (from someone other than yourself)

basically i already made a tunic text renderer in 2025 and i thought it would be funny to use it to make a tracker where everything is incomprehensible

there are other tunic renderers online [1] [2] but this one can convert any english text input thanks to a library meant for text-to-speech that includes "a pre-trained grapheme-to-phoneme model for guessing word pronunciations"

how it works

  • the main bot uses discord.py
  • it also starts a subprocess that uses archipelago.js to connect to the archipelago server
  • whenever you get a good item, the javascript file writes the data about it to a json file in a folder
  • at the same time, the bot checks the folder for new files every second
  • each text part gets split into runs of symbols/numbers (rendered with liberation serif) and alphabetic text to be tunicified
  • it uses gruut to transcribe each section of text into IPA
  • it does some processing to turn every vowel + /r/ into the corresponding rhoticized vowel and stuff like that and then the phonemes get grouped into consonant + vowel pairs in typical tunic fashion
  • each rune gets rendered with Pillow (line for the lines, circle for the round ends and the ring)
  • and then it sends it as a discord attachment with a ping
